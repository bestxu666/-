通用工法知识库
全断面开挖法
适用地质：Ⅰ、Ⅱ、Ⅲ 级围岩。岩体完整坚硬、节理不发育、无不良地质，自稳能力极强。
开挖断面: 全断面一次开挖成型
工法优势: 大型机械施工作业空间大、工序干扰少、循环进尺大
核心装备: 潜孔钻机/凿岩台车 + 装载机 + 20方自卸车
台阶法
适用地质：Ⅳ 级围岩。岩体较破碎、节理较发育、层状构造或中等埋深软硬互层岩体。
开挖断面: 分上、下两个台阶先后开挖
工法优势: 上台阶提供钻孔与初支施作平台，及早封闭初支成环
核心装备: 挖掘机 + 装载机 + 自卸汽车 + 拱架台车 + 湿喷台车
环形开挖预留核心土法
适用地质：Ⅴ 级围岩。岩体破碎极破碎、千枚岩夹层、断层破碎带、深埋高地应力大变形段。
开挖断面: 先开挖拱部环形并初支，核心土支承掌子面防坍塌
工法优势: 核心土临时支护掌子面，有效抑制围岩挤压变形
核心装备: 潜孔钻机 + 超前地质钻机 + 湿喷台车 + 挖掘机
